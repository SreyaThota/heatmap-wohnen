# HeatMap.Wohnen

A team project for **Climathon 2026 at BTU Cottbus-Senftenberg** (team of four).

## Idea
Heat waves are a health risk inside apartments, not only outdoors. HeatMap.Wohnen is a web-based, hardware-free concept that gives each apartment a **heat-stress score**, so German property managers can see which units are most at risk.

## My part
The idea, the user interface and the demo.

## Status
A concept and demo made for the event. It is not a production system, and this repository contains the project description only (no code).
